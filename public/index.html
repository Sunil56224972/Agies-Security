SCENARIO 6A: INCOMPATIBLE STACK / CHANGED CONDITION

An adversary fires a Log4j JNDI RCE exploit (ALERT-2026-9003) at target 10.0.4.22. The agent inspects the CMDB and observes the server runs Python 3.10 / FastAPI (no Java/Log4j runtime). It then checks server logs and observes HTTP 401 Unauthorized.

Agent Replanning: Rather than executing an IP block and declaring a critical compromise, the agent identifies the condition mismatch, replans its verdict to FALSE_POSITIVE / INCOMPATIBLE_STACK, refrains from blocking, and commits the evidence.

SCENARIO 6B: CONFLICT & HUMAN ANALYST OVERRIDE

A human lead analyst reviews an investigation verdict and submits an operational override via /api/soc/override with new ground-truth context. The system replans the active containment rule and deactivates/re-activates the firewall rule accordingly.
